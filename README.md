# chinese-feature-writing

中文公众号长文写作技能（Cursor / Grok Bot Skill）。

**作者：** LSC（[ChengBlack111223](https://github.com/ChengBlack111223)）

覆盖社会观察、热点评论、人物采访、关系生活、消费议题，以及新闻报道与点评的融合写法：报道准确严谨，点评有温度。

## 结构

- `SKILL.md` — 主流程与写作约定
- `references/` — 结构、语料、文风与证据、修订示例、新闻与点评
- `agents/` — Agent 配置

## 用法

在 Cursor / Grok Bot 中作为 Skill 加载：先读完整 `SKILL.md`，再按需打开 `references/` 中的参考文件。

更新于 2026-10-28。
