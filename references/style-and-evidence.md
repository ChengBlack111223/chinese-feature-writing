# 表达与证据：让材料形成声音

供起草、审稿时按需阅读。样本编号对应[样本提炼卡](corpus-map.md)（既有01–22 + 本批 B01–B20）；句段修改示例见[改稿与迁移示例](revision-and-examples.md)。学习材料的功能，不复刻原句。

## 先确定这篇文章的声音

| 主要读感 | 文字选择 | 容易写偏 |
| --- | --- | --- |
| 温暖、有人情味 | 以选择、动作、物件和关系变化承载感情，重要时刻放慢 | 为催泪编苦难，每节强行感动 |
| 犀利、有判断 | 说清责任主体、行为与后果，允许集中议论和有节制的排比 | 辱骂替代论证，把一类人写成全坏 |
| 轻调侃、冷观察 | 并置外表与成本、愿望与实际动作，适时延后评价 | 每段抖机灵，嘲笑普通人的合理需要 |
| 克制、保留复杂性 | 不同经历和解释并置，让疑问组织事实 | 只有资料排列，没有要回答的问题 |
| 共情、能理解人 | 补充缺失处境，让读者重新理解行为，再讨论选择 | 替人物诊断、猜动机，包办解决办法 |
| 具体、容易代入 | 沿着一次活动呈现需求、操作、结果及限制 | 功能清单充当故事，只写成功不交代条件 |
| 报道感、仍有温度 | 先钉来源／时间／数字／归属，再用代价与克制隐喻写判断；事实句与判断句可区分 | 空喊温暖；把判断写成假新闻；概念命名冒充法定名称 |

一篇文章有主要声音，也可以自然变化：好奇进入，解释居中，留问结束；或先愤怒，再因背景产生惋惜。变化应由材料带出，不先画强制情绪曲线。不能把所有文章平均成“温情又犀利”。

## 标题与导语各自做什么

标题选择与正文相称的入口：一个具体困惑、愿望与成本的反差、意外现象、有依据的判断，或可核的官方金句／判决结果（如本批「很好玩吗？？？」「法院判了」）。短对照标题适合轻观察，较长的事件标题适合需要交代关系的评论；不能统一成“所有人都……”和“真相令人……”。不为吸引点击放大人数、收入、危险或确定性。

导语把标题的问题落到材料上，可直接进入动作、事件进展或关键对话，也可用较长篇幅交代人物和争议。标题已经说过的结论不必换词复述几遍。导语承诺回答几个问题，结尾前就要兑现；不要为了悬念隐去会改变判断的条件。

## 句段、对话与转场

一段推进一个动作、信息单元或判断；它可以很短，也可以完整展开。结果、转折、需要停顿的句子可独立成段。复杂规则、概念辨析和连续经历允许较长段落，手机阅读不等于每句换行。

议论的多少取决于文体和任务。评论可以在证据之后集中判断，采访报道可以让多种经历并置。删除场景后同义复述的道理，保留确实解释原因、限定范围或回应异议的分析。不要规定“每段一个故事”或机械控制故事与议论比例。

对话要留下说话场景、对象及前后反应。真实口语可以迟疑、不完整、词不达意；不能把每个人都润色成金句作者。引用节目片段时注明片段来源，不用几句剪辑推断人物完整性格；虚构对话只放在已说明的创作情境中。

转场要说得出关系：前一办法遇到新阻碍，补充条件改变判断，个人经历引出组织规则，商品变化转到使用场景，一次决定产生后续劳动。若只是换一个同义例子，合并或删去；不能靠“其实”“更可怕的是”制造递进。

设问应提出读者此时会问、前文尚未回答的问题。排比、复沓和比喻服务强调或节奏，不负责填字数。重复的词或动作未必多余：同一句“下周再说”可以从期待变成推迟，同一次挂断电话可以呈现压力累积。检查重复是否改变含义、处境或力度。

## 细节不只是有画面

可用细节包括动作、物件、价格、时间、前置条件、操作步骤、失败、代价、称重差、账单跳档、指纹分布、急救耗时等可核或可感信息。感官入口（米香、跳档）服务硬新闻时，随后必须接到数据或规则。选择能改变理解的细节，而非每段装饰一个杯子、一束阳光。

- 让一个人物跨节返回时，增加其新选择、新矛盾或新条件；不重新介绍一次身份。
- 让一个物件返回时，检查它是否从使用对象变成负担、线索、关系载体或象征。象征是解释，不等于已证明的动机。
- 产品体验沿连续活动展开，保留准备过程、输入、实际结果和限制。先保存地址才能模糊询问路线的情节，不能省去保存这一步。
- 承认尝鲜、分享、退让、消费的合理需要，再讨论代价或边界；不把理解人物写成替所有行为开脱。

## 材料与可支持的结论

| 材料 | 可承担的功能 | 写作时保留什么 |
| --- | --- | --- |
| 主案例、采访和近况 | 建立过程、处境与持续变化 | 可追溯来源，真实说话者；不补内心、采访或结局 |
| 多个案例、网帖 | 展示不同条件或某种表达 | 个案不能自动证明趋势；“有人说”不等于事实 |
| 价格、收入、成本、估算 | 呈现投入、规模与落差 | 时间、地区、口径、单位；营收、利润、补贴与第三方估算分开 |
| 研究、调查和行业数据 | 提供较宽背景或检验解释 | 样本、方法与适用范围；关键局限靠近结论，不把相关写成因果 |
| 通报、规定、回应 | 解释时间线、责任与选择限制 | 日期、原文和适用条件；当事人回应仍是有归属的说法 |
| 品牌演示、产品体验 | 呈现某次任务中的操作与效果 | 厂商说法、现场体验、独立测试分别标明；一次成功不等于普遍效果 |
| 影视、节目、比喻 | 帮助理解情境或呈现某段表达 | 区分现实证明与叙事材料；剪辑不是人物全部生活 |
| 虚构生活情境 | 试验结构、声音与情节推进 | 文前统一说明，不冒称亲历、朋友故事或趋势调查 |
| 判决书、卫健通报、条例 | 钉责任与合法边界 | 日期、条文名、适用范围；白话解释紧跟原文归属 |
| 作者概念命名（「×税」「孤儿×」） | 把分散摩擦收成可讨论的对象 | 标明解释框架／比喻，非法定或官方统计；新稿不把样本命名当制度事实 |

事实底稿只需记录影响判断的关键说法、来源日期、适用范围、相反材料和未知处；日常虚构试写不必做繁重查证。需要新闻、法律、医疗、数字或现行产品能力时再核验，不能用样本中的旧信息补事实。

第一人称可以表达判断；“我采访了”“朋友告诉我”“查了资料发现”须有相应经历或实际操作。“我们”不能代替群体证据。没有采访资料就用可追溯公开材料或评论结构，不制造受访者。

标题的范围不得超过正文证据。争议、指控、回应、确认事实要区分；反转后的说法也需要证据。解释行业需求不代表认可行为，讨论社会条件不代表已确定某个人的动机。疾病不能作为道德惩罚的因果证明，不凭节目片段诊断人格。

## 温度不牺牲核实

- 读者应能指出：哪句是事实、哪句是来源说法、哪句是作者判断、哪句是比喻命名。
- 温度优先写具体代价（多付的小时、失去的黄金抢救时间、等不到的配件），少写抽象「温暖／心痛」。
- 未核实时在判断旁保留认知谦逊（「真实性也未可知」类），同时缩小结论范围。
- **样本新闻数字引语仅写法材料；新稿关键新闻、数字、政策、引语另行核实。**

融合报道与点评的步骤见[报道与点评](news-and-commentary.md)。

## 不继承的表面特征

账号标志、红字、编号、留白、音频卡、广告、求赞、视觉志「个人观点仅供参考」页脚不是正文规则。脆皮／李月亮式数字节号与决绝劝诫排比、外交纪念「始终为…」排比，均不升级为全库硬模板。样本即使只有数字节号，本技能输出仍按用户要求配置实质小标题。

“个人先退让”和“组织应保护员工”适用于不同主体；“企业有经营成本”和“人们需要公共空间”也可同时成立。保留这些张力比选择一句万能口号更有解释力。

不同产品或市场不能为扩充规模混为一谈，例如AI宠物视频、实体陪伴玩具与真实宠物智能用品。品牌案例不能仅凭文风判定有付费合作；披露以实际材料为准。
