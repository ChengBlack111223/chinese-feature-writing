# 改稿与迁移示例

用于“改一下刚才那篇”“不够像样本”“太像AI”等请求。先读取当前完整稿和最新反馈，不根据旧版问题清单盲改。用户若只要求局部调整，就处理对应部分；明确限制的范围优先。

## 把反馈变成编辑动作

| 读感或问题 | 优先检查 | 可执行的修改 |
| --- | --- | --- |
| 空、像道理集合 | 判断有没有具体对象和条件 | 加入有来源的动作、流程、关系或代价；没材料就缩小判断 |
| 重复、没有推进 | 相邻段落是否证明同一句话 | 合并同功能内容；下一节改问新条件、后果或反例 |
| 太碎、像短句拼贴 | 同一动作是否被切成很多行 | 合并承接同一信息的句子，让关键转折单独停顿 |
| 太端着、太抽象 | 是否只剩“价值、需求、困境”等名词 | 写清谁想做什么、哪里受阻、谁承担结果 |
| 场景后说教 | 解释是否只复述刚才的感受 | 删去同义总结，保留确实增加原因或边界的分析 |
| 各节像独立小作文 | 人物、物件和问题是否被反复重置 | 让前节决定产生后节后果，同一对象带着变化返回 |
| 转场生硬 | 材料之间有没有可说明的关系 | 补真实条件或换排序；不要只增加转折词 |
| 小标题空泛 | 单看标题能否知道本节发现 | 用本节新矛盾、行动或判断命名，避免只写“生活”“成长” |
| 结尾过满 | 是否突然覆盖所有问题 | 保留一项已有材料支持的变化，允许其余困难未解决 |
| 语言太平 | 各处是否同样长、同样用力 | 调整重点场景、短判断和完整分析的节奏，不强加段段金句 |
| 像喊口号／假新闻感 | 判断句是否可与事实句区分；有无来源日期与口径 | 先补可核材料再留态度；概念命名加「并非法定名称」；删无证据排比 |
| 有材料但冷冰冰 | 代价与原声是否被摘要吞掉 | 恢复具体耗时、金额、等待、原话；仍不编内心独白 |

先处理方向、事实与结构，再处理句段与用词；如果问题仅在句子，就不重新搭整篇结构。改后重读整稿，确认局部修辞没有改变事实、立场或人物关系。

## 示例一：让过程替代标签

以下四组都是新编的虚构微型示例，不是样本原句，也不是实际采访。

**只有概括：**处理闲置很麻烦，需要投入很多时间和精力。

**具体推进：**她擦干净杯口，拍了三张照片。买家问能不能寄，她翻遍储物柜，没找到合适的盒子。改约自提，对方只有周三下午有空，那时她正在上班。

动作分别增加清洁、包装、时间协调三种成本，后文可以顺着“谁来承担这些劳动”继续。无需再接三段说明“处理闲置并不容易”；若文章需要解释平台规则或家庭分工，则保留有新增信息的分析。

## 示例二：重复的话，含义发生变化

**第一次：**机器刚买回来，两人商量周末做顿早餐。“下周试试吧。”她把食谱压在盒子下面。

**第二次：**后来买家约不到时间，机器还在门边。“下周再说吧。”这一次，她把它搬回了柜子。

同一句式从安排新生活变成延后处理，形成回声。是否保留重复，取决于意义有没有改变；只把“很忙”换成“没有时间”再说一遍，应当压缩。改稿时也不要为了回声强行增写不存在的真实对话。

## 示例三：小标题让读者看见递进

**过于抽象：**01 愿望／02 现实／03 关系／04 改变。

**与这组材料匹配：**01 买了机器，早晨还是很赶／02 送走它，还得再忙一场／03 想留下的人，要不要一起挪位置／04 先让今天用的锅拿得出来。

四节分别推进使用条件、处置劳动、家庭协商和有限改变。小标题不用全部是完整句，也不用刻意押韵；重要的是准确对应本节，并在正文兑现。换题目后重新命名，不能把这一组作为通用目录。

## 示例四：留下一个实际变化

**泛化结尾：**整理物品，就是整理人生。放下执念，才能拥抱更好的自己。

**与前文问题相连：**机器还没卖出去。她只把锅挪到了前面。晚上做饭时，拉开柜门就拿到了，不必再先搬走别的东西。

结局只解决取用不便，处置难题仍在。它适合这段生活叙事，不是所有文体的默认结尾：采访可回访人物近况，评论可提出具体责任，公共议题也可保留尚无共识的问题。报道不能为获得这种收束而编造动作。


## 示例五：事实与判断分层（报道×点评）

**混成一团：**停车收费太黑了，有关部门必须立刻严惩，否则人民没有活路。

**可区分：**她停了61分钟，系统按2小时扣费。当地公示的计费规则写的是「不足1小时按1小时，超过按2小时进位」——原文如此，是否合理是另一件事。把进位写清楚，比骂一句「黑」更接近能改的规则。

前两句是可核事实与来源说法；后两句是作者判断与建议边界。改稿时先分开，再决定温度落在哪一句。

## 修订后复核

- 用户本次指出的问题是否实际改变，其他已奏效的部分是否保留？
- 所有正文小节是否有实质小标题，标题与本节内容是否匹配？
- 材料是否增加了新信息；返回的人物、物件或动作是否承担新任务？
- 事实、来源说法、作者判断、概念命名是否可区分？关键数字政策是否已另核或标明未知？
- 删除解释时是否误删因果、背景、来源或适用条件？
- 事实、虚构、引语和作者判断的边界是否仍清楚？
- 结尾是否回应本文，而非套用任何题目都成立的话？

用户要看文章，就直接交付修订稿；只有需要说明事实改动、材料缺口或对照修改时，才附简短说明。不要用冗长编辑报告替代稿件。
