# 按问题与材料选择结构

先选读者问题，再选现有材料能支持的路线。以下是可删减、组合、换序的组织方式，不是必须走完的步骤，也不规定章节数、案例数或金句位置。编号对应 corpus-map.md。

## 快速选择

| 主要问题与材料 | 可用主线 |
| --- | --- |
| 一个愿望怎样实现，有连续经历 | 1 温情人物 |
| 危险怎样形成，条件与后续较清楚 | 2 热点警示 |
| 直觉责备漏掉哪些处境 | 3 社会共情 |
| 日常互动为何卡住，双方需要什么 | 4 关系观察 |
| 交易、工作或服务如何运转 | 5 行业机制 |
| 已确认的行为越界在哪里 | 6 强立场评论 |
| 不同人对同一问题有不同经历 | 7 采访观察 |
| 商品、使用或生活方式发生变化 | 8 消费与生活观察 |
| 流行说法与资料冲突 | 9 舆情纠偏 |
| 原有解释不足，需要区分概念、主体或制度 | 10 辨析与公共议题 |
| 具体使用难处如何在体验中改变 | 11 产品体验叙事 |
| 政策民生有吐槽也有规则出处 | 12 政策民生短评（混合） |
| 公共人物离世或纪念日 | 13 讣闻与纪念 |
| 分散现象需要一个解释性命名 | 14 概念命名观察 |

样本编号：既有01–22见 corpus-map；本批记 B01–B20。无真实采访不选择虚构采访姿态；无调查材料不把观察写成行业定论。一个可靠案例也能通过经过、条件、规则和后续展开；材料少时缩小问题。

## 1. 温情人物：一个愿望怎样得到回应

样本01。以人物愿望和阻碍组织过程：尝试为何受阻，有效线索怎样出现，决定性时刻发生了什么，后来如何。重要动作放慢，背景按理解需要穿插。物件或话语可在不同阶段重新出现，但须有真实关联。

公益项目在实际起作用的位置进入，不先堆项目介绍。结尾可以让多个故事汇聚，也可以停在一个人的当前生活。没有成功结果，就写到已知进展，不代写重逢或幸福回访。

## 2. 热点警示：危险怎样形成，代价由谁承担

样本02、03、08。结果或关键选择引出风险，经过展示升级条件，必要时先纠偏，再解释环境、行为和行动限制。类比案例只在补充新机制时加入，主案详写、副案有取舍。

应对建议区分个人避险与组织保护责任。极端个案不足以推出群体普遍危险，未知动机不能补成现场心理。结尾可回到家庭代价、风险边界或仍待处理的问题，不必列技巧清单。

## 3. 社会共情：直观判断遗漏了什么

样本04；样本14可提供人物复杂性。准确呈现外界看到的行为及判断，再补影响行为的生活条件、资源和限制。明确哪些理解被修正，哪些责任仍在；最后按主体讨论可能的帮助或选择。

背景不明就保留问题，不能为了反转编出悲惨身世。理解人物不要求把他写成没有主动性、没有矛盾的人。

## 4. 关系观察：同一件事为何有不同理解

样本05、22。从互动或熟悉关系中的摩擦起笔，保留问题、回应及其前后语境；补背景，让原先的动作产生新意义。可以用不同情境或相近关系形成对照，逐步辨认被挤压的需求、时间、空间和决定权。

一个连续活动常比几个互不相干的小故事更有解释力。建议回应已出现的阻力，可以只给一两种具体反应。单方叙述不足以确认另一人的心理；节目片段也不能代表完整家庭，更不能用人格诊断替代行为分析。

## 5. 行业机制：一套生意怎样运转，成本落给谁

样本06，辅以20；本批 B13、B14。由具体价格、服务或工作变化进入，沿招募、制作、交易、履约等实际过程追踪；再解释各角色的动机、收益、约束和成本。细节可以是流程、失败、工时、包装和交接，不必全是人物表情。

热度或高收入可作入口，但须拆开流水、净收入、制作成本和补贴；既有技能也影响所谓“零门槛”。没有关键环节材料时缩小到营销或生产观察，不为了闭合利益链猜测所有人的动机。

## 6. 强立场评论：越界在哪里，为什么值得反对

样本07、21；本批 B01、B17。以事件进展、官方金句或明确行为提出判断，交代经过与相关回应，主案后接一个能增加维度的对照案；从当事人后果推进到责任要求、价值判断或正向选择。

集中议论、白话解释、短段排比可以有力度，无需强行改成中性报道。力度来自行为、反差和代价；每个案例不必另写一套结论。事实有争议时限定批评对象，疾病及偶然灾祸不能作为道德惩罚的因果证明。个人自救、家庭选择和组织追责各有适用范围。

## 7. 采访观察：同一个问题为何有不同答案

样本10、14、20；本批 B10、B16。有真实采访或可追溯人物记录时，先让读者认识人物及核心处境，再按问题交织材料。同一人跨节回归时只补新增部分，不重讲履历。

例如先呈现作品或职业吸引力，再讲实际劳动、收益与保障，最后回到去留。人物遭遇提出问题后，接相关规则或行业条件；不同经验可以相互修正。喜欢同伴、得到善意与仍想离职并不矛盾。

结尾的当下选择可检验开头的热闹，允许犹豫、失败或未定。用公开报道时保留原报道归属，不写“我们采访”；少数受访者不代表行业比例。

## 8. 消费与生活观察：行为怎样变化，新条件是什么

样本09、11、13、15；本批 B07、B09、B11。由商品、使用动作或生活摩擦进入，先让变化可见，再解释需求。可沿购买—使用—分享的过程，或沿商品—场景—传播的尺度展开。

盘点中的每一项应增加条件：热门带来排队，距离影响复用，服务位置改变办事成本。前一段留下的问题成为后一段的入口。别只把同一结论换成不同品牌或地点。

轻调侃可来自愿望与行动、价格与功能的错位；合理需求仍应被看见。必要时回望历史，改变读者对当下行为的理解。无统计时不宣布所有人改变，也不以拍照、租赁推断虚荣。结尾可停在日常动作、短问、惋惜或选择。

## 9. 舆情纠偏：哪些说法有支持，哪些仍不确定

样本12；03含局部用法。标示流行版本及其后果，按争议点对照来源和时间线；说明哪些判断应更新、哪些未知仍在；有材料时再追溯传播过程。

回应不是自动定论，删帖不是认罪，类比不是查证。没有可靠反证就写争议梳理，不预设“惊天反转”。结尾可以讨论信息判断动作，但不能把纠正某个说法扩大成全盘洗白。

## 10. 辨析与公共议题：上一层解释还漏掉什么

样本16、17、18。先承认直观解释能说清的部分，再用材料指出它的不足；区分容易混为一谈的概念、主体、责任或程序。先用日常行为说明概念，再引入必要理论。

从个人到组织再到公共条件，每次扩大尺度都要有材料桥梁。例如经营权与公众需求是两个问题，有设施与实际可使用也不同；提出问责不代表所有人同意同一种治理办法。对不同方案，写其作用与剩余困难。

同一事件、建筑、口号可贯穿全文：首次建立现场，中段解释背景，末段检验方案或增加意义。象征和历史类比属于解释，不能代替参与者实际动机的证据。生活小题不必强行升到宏观议题；结尾主体与问题层级相称。

## 11. 产品体验叙事：一个使用难处如何发生变化

样本19。先写具体适应成本，说明参与者、任务及必要前提，再沿一段连续活动呈现需求、操作、反馈和下一步。功能名称及技术解释贴着触发它们的需要进入。

模糊口语可以保留，不为展示产品把每句话改成完美指令。先前保存的信息、设置、人工协助、失败与限制会影响效果，不能删掉条件制造“无所不能”。

随后可以讨论设计理念，厂商表述保留归属；演示、个人体验、独立测试与普遍性能结论分别处理。若材料只回答适应成本，就不承诺证明就业淘汰。商业合作信息有依据才说明，不凭品牌出现次数猜测。


## 12. 政策民生短评：吐槽怎样接到规则与治理

本批 B05，辅以 B17。从可感账单、跳档收费、官方问句进入，迅速给出规则出处、适用条件与责任主体；原则升格句（如公平计价、急救资源不可戏弄）放在事实之后或与事实可区分的位置。

温度来自具体耗时、多付金额、黄金抢救时间，不是空喊「为人民」。扩案只在增加新机制或处罚维度时加入。结尾可落在可执行规则或仍待治理的缺口。无条文材料时缩小为体验观察，不假装政策解读。

## 13. 讣闻与纪念：先消息源，再记忆温度

本批 B12，辅以 B19。导语或灰框先钉：时间、年龄、消息源归属、关键病程或史实节点。再写职业生涯标志物、原声、来信、同事记忆；物件（如「眼睛」）跨节返回须增加公共含义。

不编临终对话，不把未核谣言写进悼文，不用排比歌颂改写死因或外交史实。大使随笔式「始终为…」排比属外交纪念体，不作社会观察默认腔。

## 14. 概念命名观察：一个词怎样抓住分散代价

本批 B07「AI税」、B20「孤儿车」，辅以 B09「保命3件套」。短标题抛出命名；正文用价格差、停产停服、流程节点证明该命名指向的真实摩擦。标明此为解释框架／比喻，非法定名称或官方统计。

机制段写清：谁加价、谁断供、谁难修；车主／消费者代价与法条或技术障碍并置。标题恐吓感（「完了」「税」）仅在已有机制证据时使用。结尾可问责任主体，不扩大成全体行业末日。

## 如何组合与收束

主线决定问题顺序，局部方法帮助回答问题。人物文可解释机制，消费文可引采访，评论可做纠偏；加入的内容须仍回答同一个主问题。报道与点评如何在同一篇共存，见[报道与点评](news-and-commentary.md)。

提纲可简记“本节新增理解—支撑材料—与上一节的关系”，不要求对用户展示。正文每节另拟实质小标题。选择结尾时先问：材料留下的实际状态是什么？再选择回访、回扣、建议或追问，不为完整感虚构解决。
